7.3.1. Operaciones de reducción

Clker-Free-Vector-Images (Licencia Pixabay)

Además de las operaciones predefinidas (suma, conteo, promedio, máximo, etc.) sobre colecciones, la API Streams permite realizar operaciones personalizadas conocidas como reducciones mediante el uso del método reduce. Este método toma una función que combina dos elementos en uno, permitiendo una gran flexibilidad en la forma de procesar los datos.

Aquí tienes un ejemplo donde llevamos a cabo un par de reducciones para una lista de palabras:

  1. La concatenación de todas las palabras.
  2. La localización de la palabra más larga.
import java.util.Arrays;
import java.util.List;

public class EjemploReduccion {
    public static void main(String[] args) {
        List<String> listaPalabras = Arrays.asList("Ejemplo", "de", "reducción", "en", "Java");

        System.out.println ("EJEMPLO DE OPERACIONES DE REDUCCIÓN");
        System.out.println ("-----------------------------------");
        
        System.out.printf ("Lista inicial de palabras: %s\n", listaPalabras);
        
        // Concatenar todos los elementos en una sola cadena
        String concatenadas = listaPalabras.stream()
                                   .reduce("", (a, b) -> a + b);
        System.out.printf("Todas las palabras concatenadas: %s\n", concatenadas);

        // Encontrar el elemento más largo
        String palabraMasLarga = listaPalabras.stream()
                                  .reduce((a, b) -> a.length() > b.length() ? a : b)
                                  .orElse("");
        System.out.println("Palabra más larga: " + palabraMasLarga);
    }
}

En el primer caso, la operación de reducción que se lleva a cabo es la concatenación (+):

listaPalabras.stream().reduce("", (a, b) -> a + b);

En el segundo caso es la elección de la palabra más larga:

listaPalabras.stream().reduce((a, b) -&gt; a.length() &gt; b.length() ? a : b).orElse("");

El resultado que debería aparecer sería algo así:

EJEMPLO DE OPERACIONES DE REDUCCIÓN
-----------------------------------
Lista inicial de palabras: [Ejemplo, de, reducción, en, Java]
Todas las palabras concatenadas: EjemplodereducciónenJava
Palabra más larga: reducción
