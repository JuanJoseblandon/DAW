3.3.- Conjuntos (IV). Combinando datos de varias colecciones

¿Cómo podría copiar los elementos de un conjunto de uno a otro? ¿Hay que usar un bucle for y recorrer toda la lista para ello?

¡Qué va! Para facilitar esta tarea, los conjuntos, y las colecciones en general, facilitan un montón de operaciones para poder combinar los datos de varias colecciones. Ya se vieron en un apartado anterior, aquí simplemente vamos poner un ejemplo de su uso.

Partimos del siguiente ejemplo, en el que hay dos colecciones de diferente tipo, cada una con 4 números enteros:

TreeSet<Integer> conjuntoA= new TreeSet<Integer>();
conjuntoA.add(9); conjuntoA.add(19); conjuntoA.add(5); conjuntoA.add(7); // Elementos del conjunto A: 9, 19, 5 y 7

LinkedHashSet<Integer> conjuntoB= new LinkedHashSet<Integer>();
conjuntoB.add(10); conjuntoB.add(20); conjuntoB.add(5); conjuntoB.add(7); // Elementos del conjunto B: 10, 20, 5 y 7

En el ejemplo anterior, el literal de número se convierte automáticamente a la clase envoltorio Integer sin tener que hacer nada, lo cual es una ventaja. Veamos las formas de combinar ambas colecciones:

Tipos de combinaciones.
Combinación.Código.Elementos finales del conjunto A.
Unión.Añadir todos los elementos del conjunto B en el conjunto A. conjuntoA.addAll(conjuntoB)

Todos los del conjunto A, añadiendo los del B, pero sin repetir los que ya están: 5, 7, 9, 10, 19 y 20.

Diferencia.Eliminar los elementos del conjunto B que puedan estar en el conjunto A. conjuntoA.removeAll(conjuntoB)

Todos los elementos del conjunto A, que no estén en el conjunto B: 9, 19.

Todos los elementos del conjunto A, que también están en el conjunto B: 5 y 7.

Ejercicio Resuelto

Vamos a trabajar con operaciones entre conjuntos de números enteros.

Lo primero que necesitamos es crear y rellenar un conjunto con cinco números enteros aleatorios entre 1 y 10. ¿Cómo lo harías?

Retroalimentación

Para rellenar un conjunto con un número determinado de elementos podemos ir generando números aleatorios e ir incluyéndolos en él hasta que el número de elementos del conjunto sea el deseado. Por ejemplo, se podría hacer algo así:

int n1= 1;
int n2= 10;
Cantidad = 5;

Set<Integer> conjunto = new HashSet<>();

while ( conjunto.size() < cantidad ) {
    // Generamos número aleatorio entre n1 y n2, ambos incluidos
    int numero = n1 + (int)(Math.random()*(n2-n1+1));
    // Lo añadimos al conjunto
    conjunto.add(numero);  
}

Vamos generando números entre n1 y n2 (1 y 10 en este ejemplo), y los intentamos añadir al conjunto. Si ese número ya se encuentra en el conjunto, simplemente no se vuelve a insertar. El bucle finalizará cuando el tamaño del conjunto alcance el valor cantidad, que será el número de elementos deseado para el conjunto, cinco en este caso.

Supongamos ahora que disponemos de dos conjuntos, conjuntoA y conjuntoB, y que queremos obtener cuatro nuevos conjuntos que sean el resultado de:

  1. la unión entre los conjuntos A y B (A U B);
  2. la intersección entre los conjuntos A y B ( A ∩ B );
  3. restar el conjunto B al conjunto A (diferencia A - B);
  4. restar el conjunto A al conjunto B (diferencia B - A).

Si el contenido de los conjuntos fuera, por ejemplo, el siguiente:

Conjunto A: [4, 6, 7, 8, 10]
Conjunto B: [2, 3, 5, 6, 7]

El resultado debería ser algo así:

Conjunto A unión conjunto B (AUB): [2, 3, 4, 5, 6, 7, 8, 10]
Conjunto A intersección conjunto B:  [6, 7]
Conjunto A menos conjunto B (A-B): [4, 8, 10]
Conjunto B menos conjunto A (B-A): [2, 3, 5]

Retroalimentación

Para calcular la unión podemos utilizar el método addAll implementado por cualquier clase que implemente la interfaz Collection:

Set<Integer> unionAB = conjuntoA.addAll(conjuntoB);

Para la intersección el método retainAll:

Set<Integer> interseccionAB = conjuntoA.retainAll(conjuntoB);

Y para la diferencia el método removeAll;

Set<Integer> diferenciaAB = conjuntoA.removeAll(conjuntoB);
Set<Integer> diferenciaBA = conjuntoB.removeAll(conjuntoA);
