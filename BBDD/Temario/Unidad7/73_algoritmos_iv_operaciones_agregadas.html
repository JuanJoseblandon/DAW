7.3. Algoritmos (IV). Operaciones agregadas

Las operaciones de agregación u operaciones agregadas permiten realizar cálculos y transformaciones sobre grupos de elementos, ofreciendo una manera concisa y declarativa de trabajar con datos en estructuras como listas, conjuntos o diccionarios.

¿Qué son las operaciones agregadas o de agregación? Son operaciones que permiten combinar múltiples elementos de una colección para obtener un único resultado. Se trata de operaciones como la suma, el conteo, la media, el mínimo, o el máximo.

Para trabajar apropiadamente con funciones agregas es necesario conocer el concepto de stream o flujo y el de expresiones lambda. El primero no lo veremos hasta la siguiente unidad cuando llevemos a cabo el almacenamiento externo. El segundo lo introduciremos en la unidad dedicada a las interfaces gráficas, cuando trabajemos con el framework JavaFX. Tanto la API Stream como la expresiones lambda están disponibles en Java a partir del JDK 8.

Aunque aún es pronto para entenderlo todo, vamos a ver un ejemplo básico de uso de streams y de expresiones lambda (uso del operador "flecha" ->) para llevar a cabo funciones de agregación:

import java.util.Arrays;
import java.util.List;
import java.util.NoSuchElementException;
import java.util.OptionalDouble;

public class EjemploAgregacion {
    public static void main(String[] args) {
        List<Integer> listaEnteros = Arrays.asList(1, 2, 3, 4, 5, 6, 7, 8);

        System.out.println ("EJEMPLO DE OPERACIONES DE AGREGACIÓN");
        System.out.println ("------------------------------------");
        
        // Mostramos el contenido de la lista
        System.out.printf ("Contenido de la lista: %s\n", listaEnteros);
        
        // Suma de todos los elementos
        int suma = listaEnteros.stream()
                         .mapToInt(Integer::intValue)
                         .sum();
        System.out.printf ("Suma: %d\n", suma);

        // Conteo del número de elementos
        long conteo = listaEnteros.stream().count();
        System.out.printf ("Conteo: %d\n", conteo);

        // Cálculo de la media de los elementos
        OptionalDouble promedio = listaEnteros.stream()
                                        .mapToInt(Integer::intValue)
                                        .average();
        promedio.ifPresent(avg -> System.out.printf ("Media: %.2f\n", avg));

        // Búsqueda del valor máximo
        int max = listaEnteros.stream()
                         .mapToInt(Integer::intValue)
                         .max()
                         .orElseThrow(NoSuchElementException::new);
        System.out.printf ("Máximo: %d\n", max);

        // Búsqueda del valor mínimo
        int min = listaEnteros.stream()
                         .mapToInt(Integer::intValue)
                         .min()
                         .orElseThrow(NoSuchElementException::new);
        System.out.printf ("Mínimo: %d\n", min);
    }
}

El resultado sería el siguiente:

EJEMPLO DE OPERACIONES DE AGREGACIÓN
------------------------------------
Contenido de la lista: [1, 2, 3, 4, 5, 6, 7, 8]
Suma: 36
Conteo: 8
Media: 4,50
Máximo: 8
Mínimo: 1
