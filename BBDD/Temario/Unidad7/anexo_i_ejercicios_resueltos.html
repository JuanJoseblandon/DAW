Anexo I. Ejercicios resueltos

Caso práctico

mohamed Hassan (Licencia Pixabay)

María y Juan han estado trabajando con diversos tipos de colecciones y diccionarios (maps o conjutos clave-valor) de distintos tipos, así como elaborando algoritmos para llevar a cabo búsquedas, comprobaciones, borrados, actualizaciones, etc. Combinando todas esas herramientas ya se sienten con en el entrenamiento suficiente como para intentar resolver problemas que involucren a una cierta cantidad de información y sin necesidad de utilizar arrays.

Por supuesto, aún sigue sin ser suficiente para elaborar aplicaciones completamente autónomas pues les falta, por ejemplo, que toda esa información sea persistente, es decir, que cuando el programa finalice su ejecución, todos esos datos que se encuentran en la memoria principal del ordenador no se pierdan. Pero ese será el objetivo de algunas de las siguientes unidades. Por el momento podemos afirmar que sigue creciendo el arsenal de herramientas disponibles para poder enfrentarse a los problemas que sus superiores les van proponiendo. Vamos a ver algunos de esos problemas.

Ejercicio 1. Combinando colores

webandi (Pixabay License)

Vamos a trabajar con conjuntos de String que contengan nombres de colores. Para generar nombres de colores aleatoriamente disponemos de la herramienta Utilidades.colorAleatorio(), que nos devolverá una cadena de tres caracteres que representará el nombre de un color ("NGR", "BLA", "ROJ", "VER", "AMR", "AZL").

public class Utilidades {
    private static String[] arrayColores = {"NGR", "BLA", "ROJ", "VER", "AZL", "AMR"};
    /** Devuelve un texto de tres letras que representa un color aleatorio.
     * @return un texto de tres letras que representa un color aleatorio
     */
    public static String colorAleatorio() {
        int aleatorio = (int) (Math.random() * arrayColores.length);
        return arrayColores[aleatorio];
    }
}

Escribe un programa en Java que lleve a cabo las siguientes acciones:

  1. Genere dos conjuntos de String (estructuras de tipo Set) con tres nombres de colores aleatorios cada uno donde, al tratarse de conjuntos, obviamente cada color puede aparecer una única vez en cada conjunto.
  2. Rellene un tercer conjunto con la unión de los dos conjuntos anteriores.
  3. Rellene un cuarto conjunto con la intersección.
  4. Genere un quinto conjunto con la diferencia del primer conjunto menos el segundo. Es decir quitar al primer conjunto los elementos (colores) que haya en el segundo.
  5. Muestre por pantalla el contenido de cada uno de esos conjuntos.

Un ejemplo de ejecución podría ser el siguiente:

CONJUNTOS DE COLORES
--------------------
Conjunto C1: [VER, AZL, BLA]
Conjunto C2: [AZL, NGR, ROJ]
Unión C1 y C2: [VER, AZL, BLA, NGR, ROJ]
Intersección C1 y C2: [AZL]
Diferencia C1-C2: [VER, BLA]

En este caso solo había un color en común en ambos conjuntos: el azul ("AZL").

Retroalimentación

public static void main(String[] args) {

	//----------------------------------------------
	//          Declaración de variables 
	//----------------------------------------------
	final int CANTIDAD_COLORES = 3;
	Set<String> setColores1, setColores2, union, interseccion, diferencia;
	// Al usar conjuntos (set) garantizamos que no se pueden repetir elementos
	setColores1=new HashSet<>();
	setColores2=new HashSet<>();
	
	//----------------------------------------------
	//                Entrada de datos 
	//----------------------------------------------
	// No hay, pues se usa un número fijo de elementos aleatorios
	System.out.println("CONJUNTOS DE COLORES");
	System.out.println("--------------------");

	//----------------------------------------------
	//                  Procesamiento
	//----------------------------------------------
	// Rellenamos los conjuntos con aleatorios hasta que haya CANTIDAD_COLORES
	while (setColores1.size()<CANTIDAD_COLORES) {
		// Al añadir en un conjunto, si se produce una repetición, es como si no se añadiera nada
		setColores1.add(Utilidades.colorAleatorio()); 
	}
	while (setColores2.size()<CANTIDAD_COLORES) {
		// Al añadir en un conjunto, si se produce una repetición, es como si no se añadiera nada
		setColores2.add(Utilidades.colorAleatorio()); 
	}
	
	// Unión de los dos conjuntos 
	union= new HashSet<>(setColores1);
	union.addAll(setColores2);
	
	// Intersección de los conjuntos
	interseccion= new HashSet<>(setColores1);
	interseccion.retainAll(setColores2);
	
	// Diferencia de los conjuntos
	diferencia= new HashSet<>(setColores1);
	diferencia.removeAll(setColores2);
	
	//----------------------------------------------
	//              Salida de Resultados 
	//----------------------------------------------
	// Recorremos el conjunto y mostramos su contenido por pantalla
	System.out.printf ("Conjunto C1: %s\n", setColores1);
	System.out.printf ("Conjunto C2: %s\n", setColores2);
	System.out.printf ("Unión C1 y C2: %s\n", union);
	System.out.printf ("Intersección C1 y C2: %s\n", interseccion);
	System.out.printf ("Diferencia C1-C2: %s\n", diferencia);

	System.out.println();
}

Ejercicio 2. Vaciado de lista

Savana Price (Pixabay License)

Implementa un programa en Java donde:

  1. se rellene una estructura de tipo lista con doce números enteros aleatorios entre 1 y 5 (ambos incluidos) y se muestre su contenido por pantalla;
  2. a continuación se observará el contenido del primer elemento de la lista y se eliminarán de ella todos los elementos que tengan ese valor, volviéndose a mostrar cómo ha quedado la lista tras el borrado;
  3. tras esto se observará nuevamente el valor del primer elemento de la lista (que necesariamente será otro diferente al del paso anterior, pues todas las posibles apariciones de ese valor habrán sido eliminadas) y se borrarán también todos los elementos que tengan ese valor, mostrando de nuevo el contenido de la lista;
  4. se siga procediendo de ese modo hasta que la lista quede completamente vacía.

Aquí tienes un posible ejemplo de ejecución:

VACIADO DE LISTA
----------------
Contenido inicial de la lista: [5, 3, 5, 2, 1, 1, 4, 3, 3, 4, 1, 4]
Procedemos a ir vaciando su contenido.

Eliminamos todas las apariciones del primer elemento: 5
Lista resultante: [3, 2, 1, 1, 4, 3, 3, 4, 1, 4]

Eliminamos todas las apariciones del primer elemento: 3
Lista resultante: [2, 1, 1, 4, 4, 1, 4]

Eliminamos todas las apariciones del primer elemento: 2
Lista resultante: [1, 1, 4, 4, 1, 4]

Eliminamos todas las apariciones del primer elemento: 1
Lista resultante: [4, 4, 4]

Eliminamos todas las apariciones del primer elemento: 4
Lista resultante: []

Retroalimentación

public static void main(String[] args) {
	//----------------------------------------------
	//          Declaración de variables 
	//----------------------------------------------
	final int CANTIDAD_NUMEROS = 12;
	List<Integer> listaEnteros = new ArrayList<>();

	//----------------------------------------------
	//               Entrada de datos 
	//----------------------------------------------
	System.out.println("VACIADO DE LISTA");
	System.out.println("----------------");
	// No hay, pues se usa un número fijo de elementos aleatorios

	// Rellenamos la lista con aleatorios hasta que haya CANTIDAD_NUMEROS
	for (int i = 0; i < CANTIDAD_NUMEROS; i++) {
			int aleatorio = 1 + (int) (Math.random() * 5);
		listaEnteros.add(aleatorio);
	}
	System.out.printf("Contenido inicial de la lista: %s\n", listaEnteros.toString());

	//----------------------------------------------
	//      Procesamiento + Salida de resultados
	//----------------------------------------------
	System.out.printf("Procedemos a ir vaciando su contenido.\n\n");

	while (!listaEnteros.isEmpty()) {
		int primerElemento = listaEnteros.get(0);
		System.out.printf("Eliminamos todas las apariciones del primer elemento: %d\n", primerElemento);
		while (listaEnteros.contains(primerElemento)) {
			listaEnteros.remove((Integer) primerElemento);
		}
		System.out.printf("Lista resultante: %s\n\n", listaEnteros.toString());
	}
}

Ejercicio 3. Búsqueda de coincidentes

Hans Braxmeier (Pixabay License)

Implementa un programa en Java donde:

  1. Se rellenen dos estructuras de tipo lista (List) con diez nombres aleatorios de colores (objetos de la clase String) usando la herramienta Utilidades.colorAleatorio y se muestre su contenido por pantalla.
  2. Se inspeccionen ambas listas y si tienen el mismo color en la misma posición:
    1. se "tachará" ese color de ambas listas sustituyéndolo por la cadena "---";
    2. se almacenará ese color en una lista de colores eliminados;
    3. se almacenará la posición en la que se encontraba ese color en una lista posiciones eliminadas.
  3. Se muestre por pantalla:
    1. el contenido final de la primera lista de colores (con algunas posiciones "tachadas");
    2. el contenido final de la segunda lista de colores (con las mismas posiciones "tachadas");
    3. la lista de colores eliminados;
    4. la lista de posiciones eliminadas;
    5. el conjunto de colores eliminados (sin repetir).

Aquí tienes un posible ejemplo de ejecución.

BÚSQUEDA DE COINCIDENTES
------------------------
1. Contenido inicial de la lista1: [NGR, ROJ, VER, BLA, BLA, ROJ, AMR, NGR, NGR, BLA]
2. Contenido inicial de la lista2: [AZL, AZL, BLA, NGR, AMR, NGR, NGR, NGR, VER, BLA]

1. Contenido final de la lista 1:  [NGR, ROJ, VER, BLA, BLA, ROJ, AMR, ---, NGR, ---]
2. Contenido final de la lista 2:  [AZL, AZL, BLA, NGR, AMR, NGR, NGR, ---, VER, ---]
3. Contenido final de la lista de colores eliminados: [NGR, BLA]
4. Contenido final de la lista de posiciones eliminadas: [7, 9]
5. Contenido final del conjunto de colores eliminados: [BLA, NGR]

En este ejemplo concreto se han producido dos coincidencias: en la posición 7 (color "NGR") y en la posición 9 (color "BLA").

Retroalimentación

public static void main(String[] args) {
	//----------------------------------------------
	//          Declaración de variables 
	//----------------------------------------------
	final int CANTIDAD_COLORES = 10;
	List<String> listaColores1 = new ArrayList<>();
	List<String> listaColores2 = new ArrayList<>();
	List<String> listaColoresEliminados = new ArrayList<>();
	Set<String> setColoresEliminados = new HashSet<>();
	List<Integer> listaPosicionesEliminadas= new ArrayList<>();
	
	//----------------------------------------------
	//               Entrada de datos 
	//----------------------------------------------
	System.out.println("BÚSQUEDA DE COINCIDENTES");
	System.out.println("------------------------");
	// No hay, pues se usa un número fijo de elementos aleatorios

	// Rellenamos la lista con aleatorios hasta que haya CANTIDAD_COLORES
	for (int i = 0; i < CANTIDAD_COLORES; i++) {
		listaColores1.add(Utilidades.colorAleatorio()); 
	}
	System.out.printf("1. Contenido inicial de la lista1: %s\n", listaColores1.toString());

	for (int i = 0; i < CANTIDAD_COLORES; i++) {
		listaColores2.add(Utilidades.colorAleatorio()); 
	}
	System.out.printf("2. Contenido inicial de la lista2: %s\n", listaColores2.toString());
	System.out.println();
	
	//----------------------------------------------
	//               Procesamiento
	//----------------------------------------------

	// Recorremos a la vez las dos listas
	for (int i=0; i<listaColores1.size(); i++) {
		String color=listaColores1.get(i);
		// Comprobamos si en la misma posición encontramos el mismo color en ambas listas
		if (color.equals(listaColores2.get(i))) { 
			listaColoresEliminados.add(color);  // Se incluye ese color en la lista de eliminados
			setColoresEliminados.add(color);
			listaPosicionesEliminadas.add(i);   // Se incluye la posición en la lista de posiciones
			listaColores1.set(i, "---");          // Se "tacha" ese color en las listas originales
			listaColores2.set(i, "---");
		}
	}

	//----------------------------------------------
	//            Salida de resultados
	//----------------------------------------------
	System.out.printf("1. Contenido final de la lista 1:  %s\n", listaColores1.toString());
	System.out.printf("2. Contenido final de la lista 2:  %s\n", listaColores2.toString());
	System.out.printf("3. Contenido final de la lista de colores eliminados: %s\n", listaColoresEliminados.toString());
	System.out.printf("4. Contenido final de la lista de posiciones eliminadas: %s\n", listaPosicionesEliminadas.toString());
	System.out.printf("5. Contenido final del conjunto de colores eliminados: %s\n", setColoresEliminados.toString());
	
}

Ejercicio 4. Clasificación de coincidentes

Brett Hondow en (Pixabay License)

Implementa un programa en Java donde:

  1. Se rellenen dos estructuras de tipo lista con quince nombres aleatorios de colores y se muestre su contenido por pantalla, de manera similar a como ya se ha hecho en el ejercicio 2.
  2. Se declare y reserve espacio para una estructura de tipo Map donde las claves sean nombres de colores (objetos de tipo String) y los valores sean listas de números enteros (List<Integer>). Es decir, que se tratará de una estructura de tipo Map<String, List<Integer>>.
  3. Se inspeccionen ambas listas y, si tienen el mismo color en la misma posición, se llevarán a cabo las siguientes operaciones en el Map:
    1. si ese color aún no existe como clave, se introducirá como nueva clave y se le asignará una nueva lista de enteros vacía;
    2. se asignará, a la lista correspondiente a ese color, la posición en las listas de origen en la que ha sido encontrada la coincidencia.
  4. Se muestre por pantalla la estructura de tipo Map.

Aquí tienes un ejemplo de ejecución donde se han producido cuatro coincidencias: azul en la posición 4, amarillo en la 1, y negro en las posiciones 2 y 14:

CLASIFICACIÓN DE COINCIDENTES
-----------------------------
Contenido inicial de la lista1: [AMR, AMR, NGR, AZL, AZL, NGR, BLA, ROJ, NGR, NGR, AMR, BLA, AZL, BLA, NGR]
Contenido inicial de la lista2: [BLA, AMR, NGR, NGR, AZL, ROJ, AMR, NGR, VER, VER, NGR, AZL, BLA, ROJ, NGR]

Clasificación de coincidencias: {AZL=[4], AMR=[1], NGR=[2, 14]}

Retroalimentación

public static void main(String[] args) {
	//----------------------------------------------
	//          Declaración de variables 
	//----------------------------------------------
	final int CANTIDAD_COLORES = 15;
	List<String> listaColores1 = new ArrayList<>();
	List<String> listaColores2 = new ArrayList<>();
	Map<String, List<Integer>> mapCoincidencias = new HashMap<>();

	//----------------------------------------------
	//               Entrada de datos 
	//----------------------------------------------
	System.out.println("CLASIFICACIÓN DE COINCIDENTES");
	System.out.println("-----------------------------");
	// No hay, pues se usa un número fijo de elementos aleatorios

	// Rellenamos la lista con aleatorios hasta que haya CANTIDAD_COLORES
	for (int i = 0; i < CANTIDAD_COLORES; i++) {
		listaColores1.add(Utilidades.colorAleatorio());
	}
	System.out.printf("Contenido inicial de la lista1: %s\n", listaColores1.toString());

	for (int i = 0; i < CANTIDAD_COLORES; i++) {
		listaColores2.add(Utilidades.colorAleatorio());
	}
	System.out.printf("Contenido inicial de la lista2: %s\n", listaColores2.toString());
	System.out.println();

	//----------------------------------------------
	//                 Procesamiento
	//----------------------------------------------
	for (int i = 0; i < listaColores1.size(); i++) {
		String color = listaColores1.get(i);
		if (color.equals(listaColores2.get(i))) {
			if (!mapCoincidencias.containsKey(color)) {
				mapCoincidencias.put(color, new ArrayList());
			}
			mapCoincidencias.get(color).add(i);
		}
	}

	//----------------------------------------------
	//            Salida de resultados
	//----------------------------------------------
	System.out.printf("Clasificación de coincidencias: %s\n", mapCoincidencias);

}

Ejercicio 5. Clasificación de fechas por día de la semana

200Degrees (Pixabay License)

Nos han pedido implementar un programa en Java que rellene de manera automática una estructura de tipo Map donde:

  1. Las claves serán de tipo Month.
  2. Los valores serán nuevas estructuras de tipo Map donde:
    1. Las claves serán de tipo DayOfWeek.
    2. Los valores serán estructuras de tipo Set de referencias a objetos LocalDate (Set<LocalDate>). En ese conjunto se almacenarán las fechas que correspondan, en un mes determinado, a un día de la semana determinado de un determinado año que se habrá introducido por teclado.

Resumiendo, se trataría de una estructura de tipo Map<Month, Map<DayOfWeek, Set<LocalDate>>>.

La idea es que para cada mes del año (claves de Month.JANUARY a Month.DECEMBER) se pueda consultar cada día de la semana (de DayOfWeek.MONDAY a DayOfWeek.SUNDAY) para obtener un conjunto (Set) que contenga todas las fechas que caen en ese día de la semana de ese mes.

Por ejemplo, para el año 2022, tendremos un Map de doce elementos (uno para cada mes del año) donde, por ejemplo, el valor correspondiente a la clave Month.JANUARY será un nuevo Map de siete elementos (uno para cada día de la semana) donde, por ejemplo, el valor correspondiente a la clave DayOfWeek.MONDAY será un Set de cuatro elementos con el siguiente contenido [07/02/2022, 14/02/2022, 21/02/2022, 28/02/2022].

/**
 * Clase que permite comparar dos objetos <code>CitaLiteraria</code> usando como criterio
 * de comparación el <strong>contenido (texto) de esas citas</strong>. Se trata de una comparación
 * alfabética o lexicográfica.
 * @author profe
 */
public class ComparadorCitasPorTexto implements Comparator<CitaLiteraria> {
    
    /**
    * Comparación de dos objetos de tipo <code>CitaLiteraria</code> usando como criterio
    * de comparación el <strong>contenido (texto) de esas citas</strong>. Es una comparación de tipo
    * lexicográfica (la que se hace entre dos <code>String</code>). El resultado de la comparación sería: 
    * <ul>
    * <li>negativo si la primera cita es "menor" o se colocara "antes" que la 
    * segunda si hubiera que ordenarlas (alfabética o lexicográficamente está antes),</li>
    * <li>cero si se consideran "iguales" o "equivalentes" según este criterio
    * (los dos títulos son exactamente la misma cadena de caracteres),</li> 
    * <li>positivo si la primera cita es "mayor" o se colocara "depués" que la segunda 
    * si hubiera que ordenarlas.</li>
    * </ul>
    * @param c1 primer término de la comparación (primera cita)
    * @param c2 segundo término de la comparación (segunda cita)
    * @return resultado de la comparación
    */
    @Override
    public int compare (CitaLiteraria c1, CitaLiteraria c2) {
        return c1.getTexto().compareToIgnoreCase(c2.getTexto());
    }
}

    * de cada cita). El resultado de la comparación sería: 
    * <ul>
    * <li>negativo si la primera cita es "menor" o se colocara "antes" que la 
    * segunda si hubiera que ordenarlas (menos veces citada),</li>
    * <li>cero si se consideran "iguales" o "equivalentes" según este criterio
    * (mismas veces citada),</li> 
    * <li>positivo si la primera cita es "mayor" o se colocara "depués" que la segunda 
    * si hubiera que ordenarlas (más veces citada).</li>
    * </ul>
    * @param c1 primer término de la comparación (primera cita)
    * @param c2 segundo término de la comparación (segunda cita)
    * @return resultado de la comparación    
    */
    @Override
    public int compare (CitaLiteraria c1, CitaLiteraria c2) {
        return c1.getUsos().size() -  c2.getUsos().size();
    }   
}
